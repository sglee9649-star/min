# 영어 스피킹 평가 플랫폼

영어 AI 리텔링 대회 운영 + 학생 스피킹 연습(리텔링 / 보고 읽기 / 질문 답변) 웹앱.

- 프로젝트 명세서: [CLAUDE.md](./CLAUDE.md)
- 평가항목 전체 카탈로그: [docs/EVALUATION_CRITERIA.md](./docs/EVALUATION_CRITERIA.md)

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 현재 상태: 6단계 완료 (관제 + 집계) — 전 단계 기능 구현 완료

다크/화이트 모드 전환(우상단 버튼), 관리자·심사위원 화면 한/영 병기 지원.

| 화면 | 주소 | 내용 |
|---|---|---|
| 입장 | `/` | 대회명 표시 + 역할 선택 |
| 참가자 | `/participant` | 참가번호 → 대기 → 읽기 타이머 → 자동 녹음 → 기기에 저장 |
| 심사위원 | `/judge` | 접속코드 `judge2026` (임시) · 본인 선택 → 참가번호별 루브릭 채점 → 결과 링크 전송 |
| 심사 설정 | `/admin/judging` | 루브릭 빌더(항목+비중), AI 반영 비율, 심사위원·참가자 명단, 설정 링크 공유 |
| 진행 현황 | `/admin/progress` | 심사위원×참가자 제출 현황표, 채점 결과 링크 반영 |
| 결과 집계 | `/admin/results` | 가중치·AI 반영 집계, 편차 보정, 동점 처리, 공개 전환 |
| 데이터 관리 | `/admin/data` | CSV 다운로드(결과·상세), 데이터 삭제, 감사 로그, 보관 안내 |
| 관리자 | `/admin` | 접속코드 `admin2026` (임시) · 대회명/타이머 설정 동작함 |
| 문제 생성 | `/admin/generate` | 학년·레벨·카테고리/키워드 → AI 지문·질문 생성 (API 키 필요) · 보관함에서 "출제하기" |
| 녹음 관리 | `/admin/recordings` | 녹음 듣기·다운로드·삭제 + 🤖 AI 평가 (Whisper 전사 → 항목별 점수 + 근거) |
| 발표 화면 | `/display` | 프로젝터용 대회명 표시 |

⚠️ 접속코드는 개발용 임시 장치입니다. 실제 대회 전(2단계)에 Supabase 로그인으로 교체됩니다.

## API 키 설정 (문제 생성에 필요)

1. `.env.example`을 복사해 `.env.local` 파일을 만듭니다.
2. `ANTHROPIC_API_KEY=` 뒤에 발급받은 키를 붙여넣습니다.
3. `npm run dev`를 다시 시작합니다.

Vercel에 배포할 때는 Vercel 프로젝트 설정 → Environment Variables에 같은 이름으로 키를 등록하세요.

## 대회 흐름 테스트 방법 (한 브라우저에서)

1. 관리자(`/admin/generate`)에서 문제 생성 → 보관함에 저장 → "출제하기"
2. 새 탭에서 참가자(`/participant`) 입장 → 참가번호 입력 → 자동으로 시작
3. 읽기 타이머 → 자동 녹음 → 종료 후 관리자 "녹음 관리"에서 확인

Supabase 도입 전까지 문제 출제·녹음 공유는 같은 브라우저 안에서만 동작합니다.

## 심사 흐름 (5단계)

1. 관리자 → 심사 설정: 루브릭 구성, 심사위원·참가자 등록, 저장 → "심사 설정 링크 만들기"
2. 심사위원 태블릿에서 링크/QR 열기 → 접속코드 → 본인 선택 → 참가번호 눌러 채점
3. 채점 후 "채점 결과 보내기" 링크를 관리자에게 전송 → 관리자가 열면 진행 현황표에 반영

## 결과 발표 흐름 (6단계)

1. 심사위원 채점 결과를 관리자가 진행 현황에서 취합
2. 관리자 → 결과 집계: 편차 보정 방식·동점 규칙 선택 → 순위 확인
3. "결과 공개" 전환 → 발표 화면(/display)에 순위 표시
4. 데이터 관리에서 CSV 백업 → 대회 후 데이터 삭제

## 남은 확장 (Supabase 도입 시)

현재는 서버 없이 링크/QR로 기기 간 데이터를 전달합니다. Supabase를 도입하면:
실시간 다기기 동기화, 실제 로그인 인증, 녹음 서버 저장·자동 파기, 녹음 후채점 모드가 가능해집니다.
